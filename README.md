# Opname & Oplevering · De Laat Bouwbegeleiding

Losse versie van de app (zonder claude.ai), voor kantoor en inspecteurs.
Draait op GitHub Pages; gegevens en inloggen in Firebase.

Bestanden delen: via Firebase Storage (Blaze-abonnement nodig) of een andere opslag; zie shim.js.

- Gegevens overzetten: in de claude.ai-versie **Back-up** maken, in de nieuwe versie **Herstel back-up**.
- Binnen de app regelt de pincode per gebruiker de toegang. De database is alleen bereikbaar voor wie de app opent (anoniem aangemeld).
